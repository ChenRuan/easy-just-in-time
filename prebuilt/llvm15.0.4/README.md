Temporary prebuilt host artifacts for LLVM 15.0.4.

Files in this directory were built from:
- LLVM tag `llvmorg-15.0.4`
- EasyJIT branch `llvm15`

Artifacts:
- `EasyJitPass.so`: host-side pass plugin loaded by `clang`
- `libEasyJitRuntime.so`: host-side runtime library

This directory is intended as a short-term bootstrap path for internal hosts.
